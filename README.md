# Dev-tools

macOS dev setup: VS Code, iTerm2, zsh (Oh My Zsh + Powerlevel10k), Docker, Python (uv, conda for legacy).

## Software

- [VS Code](https://code.visualstudio.com/): editor
- [iTerm2](https://iterm2.com/): terminal
- [Docker Desktop](https://www.docker.com/products/docker-desktop/): containers
- [DB Browser for SQLite](https://sqlitebrowser.org/): explore db
- [Beyond Compare](https://www.scootersoftware.com/): diff files
- [MacPass](https://macpassapp.org/): store passwords
- [Cyberduck](https://cyberduck.io/): sftp, s3... client
- [Miniconda](https://docs.anaconda.com/free/miniconda/index.html): python env management (legacy projects only, e.g. `_amplisim`)
- [chezmoi](https://www.chezmoi.io/): dotfiles management, see the [quick start](https://www.chezmoi.io/quick-start/#start-using-chezmoi-on-your-current-machine)

## Console

- [Oh My Zsh](https://ohmyz.sh/): zsh framework (plugin: `git`)
- [Powerlevel10k](https://github.com/romkatv/powerlevel10k): prompt theme, config in `~/.p10k.zsh` (generated by `p10k configure`)
- Possible migration: [Starship](https://starship.rs/) (actively maintained, TOML config)

Oh My Posh is no longer used.

## Tracked dotfiles

- `.zshrc`, `.zprofile`: zsh config (env and PATH in `.zprofile`, interactive stuff in `.zshrc`)
- `.p10k.zsh`: prompt config
- `.oh-my-zsh/custom/aliases.zsh`: custom aliases on top of Oh My Zsh
- `.vimrc`: vim config
- `.bashrc`: legacy, kept as a base only
- `conda_py3dev.yml`: conda env file

### Not tracked on purpose

- `~/.ssh`: contains private keys and reveals services/accounts. Backed up by Time Machine (encrypted volume).
- atuin database (`~/.local/share/atuin`): use `atuin sync` instead.
- `~/.zcompdump*`, `~/.oh-my-zsh/cache`: generated data.
- Any token or secret (e.g. `UV_PUBLISH_TOKEN`): never in a tracked file.

## zsh setup notes

### `.zshrc` layout (order matters)

```zsh
# Tools (order matters: atuin last so it owns Ctrl+R)
eval "$(direnv hook zsh)"
command -v fzf    >/dev/null && source <(fzf --zsh)
command -v zoxide >/dev/null && eval "$(zoxide init zsh)"
command -v atuin  >/dev/null && eval "$(atuin init zsh)"

# 6. p10k config, then zprof report
```

### Startup time lessons

- Conda auto-activation of `base` cost the most, use lazy loading  (function that runs the hook on first `conda` call).
- `ZSH_COMPDUMP` containing `$HOST` forced a full completion rebuild whenever the hostname changed.
- Docker Desktop may re-inject its `compinit` block into `.zshrc` after an update: remove it if startup gets slow again.
- Do not run `uv generate-shell-completion` at startup. Generate it once:

```bash
mkdir -p ~/.zfunc && uv generate-shell-completion zsh > ~/.zfunc/_uv
```


### Tool usage

```bash
# zoxide
z proj                      # jump to best match
zi                          # interactive (needs fzf)
zoxide query -ls            # list directories with scores
zoxide remove ~/old/path    # delete an entry

# atuin
atuin import auto           # import existing zsh history (once)
atuin stats                 # most used commands
```

`Ctrl+R` -> atuin, `Ctrl+T` / `Alt+C` / `**<Tab>` -> fzf. On iTerm2, `Alt+C` needs *Profiles > Keys > Left Option key = Esc+*.

## SSH

One `Host` block per service in `~/.ssh/config`, specific blocks before `Host *`:

```text
Host github.com
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_github
    IdentitiesOnly yes

Host *
    AddKeysToAgent yes
    UseKeychain yes
```

```bash
# Load every private key into the macOS Keychain (one-shot, never in .zshrc)
for key in ~/.ssh/id_*; do
  [[ "$key" == *.pub ]] && continue
  ssh-add --apple-use-keychain "$key"
done

ssh-add -l                  # keys currently in the agent
ssh -T git@github.com       # test authentication

# Switch a remote from HTTPS to SSH (fixes "Password authentication is not supported")
chezmoi git remote -v
chezmoi git remote set-url origin git@github.com:<user>/<repo>.git
```

## chezmoi

### Initial setup

```bash
chezmoi init
chezmoi add ~/.zshrc ~/.zprofile ~/.p10k.zsh
chezmoi add ~/.oh-my-zsh/custom/aliases.zsh
chezmoi add ~/.vimrc ~/.bashrc
```

Never run a recursive `chezmoi add` on `~/.oh-my-zsh` (git repo with cache and plugins) or `~/.ssh` (private keys).

### Daily workflow

After editing a file directly in `~`, run `chezmoi re-add`, otherwise the next `chezmoi apply` overwrites the change.

```bash
chezmoi managed                   # list all managed files (targets in ~)
chezmoi managed --include=files   # files only, no directories
chezmoi unmanaged ~/.config       # untracked files (restrict to a dir, $HOME is noisy)
chezmoi status                    # what differs between ~ and the source
chezmoi diff                      # same, with the actual diff
chezmoi source-path               # source dir (~/.local/share/chezmoi)

chezmoi add <file>                # start tracking
chezmoi re-add [<file>]           # copy ~ changes into the source
chezmoi apply                     # source -> ~
chezmoi forget <file>             # stop tracking, keep file in ~
chezmoi edit <file>               # edit the source version
chezmoi cd                        # shell in the source dir (git status/commit/push)
chezmoi git push                  # push from anywhere
```

### Before pushing (the repo is public)

```bash
chezmoi cd
git grep -n "UV_PUBLISH_TOKEN\|pypi-"   # current state, no output = clean
git log -S"pypi-" --oneline             # history, no output = clean
```
